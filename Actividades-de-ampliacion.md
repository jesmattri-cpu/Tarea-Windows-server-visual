2.53.
 
Busca en internet las ventajas y novedades que presenta Windows Server 2019 con respecto a Windows Server 2016 y versiones anteriores.

R.2.53.- Las ventajas principales es que Windows server 2019 ofrece mas seguridad y funcionalidad que Windows server 2016, aquí hay algunos ejemplos:

-Enfoque híbrido para llegar a la nube (Esto permite que las soluciones instaladas fuera de linea, en linea parcialmete y totalmente en linea se puedan aplicar en el mismo ordenador).

-Ha mejorado la seguridad. (en windows server 2016 ya existian medidad de seguridad pero la versión de 2019 agregó un función con enfasis en proteger, detectar y responder para hacer eso han  ha prestado especial atención a la prevención de ataques con la Protección contra amenazas avanzada de Windows Defender. Windows Server 2019 tiene una nueva funcionalidad para un soporte más extenso de VMConnect, que puede conectar diferentes máquinas virtuales, y una versión mejorada de solución de problemas para las máquinas virtuales blindadas. Con la versión más reciente de 2019, podrá proteger mejor su red encriptada, con la actualización no solo su red está mejor protegida, sino que también la conexión entre los diferentes servidores se proporciona con mayor seguridad.  

-Application windows plataform 2019 

incluye nuevos desarrollos en el campo de los Contenedores de Windows Server (en los que puede detener y mover aplicaciones) y el Subsistema de Windows para alojar Linux. El tamaño del núcleo base del servidor de la imagen del contenedor se ha reducido considerablemente. Esto aumenta significativamente los desarrollos y el rendimiento.
